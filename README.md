# かけこみ辞典

むずかしい言葉に出会ったとき、かけこむ場所です。

ITやAIの言葉を、興味のない普通の人が読んで「勉強になったな」と思える超短文で説明する用語辞典を作るための仕組みです（語彙は小学生高学年でも読める水準）。
言葉の説明を書いたファイルを置いて、作成の合図を1回出すと、
ホームページが丸ごとできあがります。

NPO法人AIかけこみ寺（設立認証申請中）が作りました。

## これは何をするものか

- 言葉の説明を書いたテキストを、読みやすいページに整えます
- 全部の言葉をジャンル別にならべた一覧ページを自動で作ります
- むずかしさやジャンルのボタンで絞り込めます
- 言葉のむずかしさを4段階（初級・中級・上級・特級）で色分けします
- できあがったページは、インターネットの向こうの何かを一切読みに行きません。
  持ち歩いても、社内だけで置いても、そのまま動きます

## 使いはじめる

パソコンに Node.js（無料の道具）が入っている前提です。
入っていなければ https://nodejs.org からダウンロードしてください。

```bash
npm install      # 最初の1回だけ。必要な部品をそろえます
npm run build    # ページを作ります
npm run serve    # ブラウザで http://localhost:8080 を開いて確認します
```

うまくいかないときは、`npm run build` が出したメッセージを読んでください。
何行目の何が足りないかを日本語で教えてくれます。

## 言葉を1つ追加する

1. `content/` フォルダに、新しいテキストファイルを1つ作ります
2. `content/rls.md` をそのままコピーして、中身を書きかえるのが一番早いです
3. `npm run build` を実行します
4. 足りないところがあれば止まって教えてくれるので、直してもう一度実行します

## AIに手伝ってもらう（コピペ用）

このリポジトリは、Claude Code のようなAIエージェントに改造させることを前提に作っています。
下の文をそのままコピーして貼りつけてください。

**言葉を1つ追加してもらうとき**

```
このリポジトリ（かけこみ辞典）に「〇〇」という言葉の説明を追加してください。
まず CLAUDE.md を読んで、決まりごとを守ってください。
content/rls.md を見本にして content/〇〇.md を作り、
読む人はその話題に興味のない普通の人だと思って、
本文全体400〜600字の超短文で、たとえ話を1つだけ入れて書いてください。
語彙は小学生高学年でも読める水準にしてください。
出典は公式の説明ページだけを使い、実在するか確かめてください。
最後に npm run build と npm test を実行して、両方通ることを確認してください。
```

**見た目を変えてもらうとき**

```
このリポジトリ（かけこみ辞典）の見た目を「〇〇」のように変えてください。
まず CLAUDE.md を読んでください。
変えていいのは assets/wiki.css と templates/article.html だけです。
できあがったページ（index.html や rls/index.html）を直接いじってはいけません。
外部のインターネット上のファイルを読み込む書き方は使わないでください（例外は今使っているGoogle Fontsの文字だけ）。
最後に npm run build と npm test を実行して、両方通ることを確認してください。
```

**動きがおかしいとき**

```
このリポジトリ（かけこみ辞典）で npm run build を実行したらエラーが出ました。
CLAUDE.md を読んだうえで、原因を調べて直してください。
直したあと npm test も実行して、26本のテストが全部通ることを確認してください。
```

## 決まりごとの数

- 説明ファイルの書式チェック: **11のルール**（＋本文の必須見出し4つのチェック）
- 自動テスト: **26本**（`npm test` で実行）

ルールに1つでも違反があると、ページは作られません。
まちがったページが公開されてしまうより、作られない方が安全だからです。

## ほぼ手元だけで動きます

- 絞り込みの仕組みはすべてこのフォルダの中だけで完結し、押したボタンの情報がどこかに送られることもありません
- 外部から読み込むのは文字のデザイン（Google Fontsの丸い書体。公式サイトと同じもの）だけです
- インターネットにつながっていないパソコンでも開けます（その場合は文字の形だけ普通のゴシック体になります）

## 限界（できないこと）

- **説明の中身の正しさは保証しません。** 書式が正しいかは自動で見ますが、
  説明が事実として合っているかは人が確かめる必要があります
- **言葉が数千個をこえると一覧や絞り込みが重くなります。** すべての言葉を1つずつ調べる
  単純な作りだからです。数百個までなら快適です
- **書式チェックはゆるい部分があります。** 決まった形の書き方だけを読めるように
  作ってあるので、凝った書き方をすると読めずに止まります
- **見た目の確認は自動化していません。** 色やレイアウトが崩れていないかは、
  `npm run serve` で目で見て確かめてください
- **むずかしさの4段階は人が決めます。** 自動判定はしません
