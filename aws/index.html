AWS上級

Amazon Web Servicesアマゾン・ウェブ・サービスアマゾンが貸している計算の設備

アマゾンが貸している、計算する設備の一式です。

なぜ大事?

ここが止まると、世界中のサービスが同時に止まります。 実際に何度か起きていて、そのたびに「1社に寄りすぎでは」という議論になります。便利さと、集中していることの怖さが同居しています。

やさしい解説

サービスを動かすには、計算する機械と、置いておく場所と、つなぐ回線が要ります。自分で買うと高く、増やすのも減らすのも大変です。

AWSは、それを必要な分だけ借りられるようにしたものです。使った分だけ払い、要らなくなれば止められます。小さく始めて、人が増えたら増やす。この形が当たり前になったのは、ここからです。

借りられるものは細かく分かれていて、計算する場所、置いておく場所、データベース、AIを動かす場所と、何百種類もあります。多すぎて選ぶのが難しいのが、初めての人がつまずくところです。

競う相手は、マイクロソフトとグーグルのクラウドです。AIが増えるほど計算する場所が要るので、この3社の商売は伸びています。

例文

  • 「AWSって何?」「アマゾンが貸している計算の設備だよ。多くのサービスがこの上で動いている」
  • 「AWSが止まったってニュース見た」「あちこち同時に止まるからね。1社に寄りすぎという議論になるんだ」
