CLAUDE.mdクロード・ドット・エムディー

Claude Code が作業のたびに最初に読む、「決まりごと」を書いたファイルです。

なぜ大事?

AIは会話が終わると忘れます。毎回説明し直すことを、一度書いておけばよくなるのがこのファイルです。うちの店はこういう客層で、こういう言葉は使わない、ここのファイルは外に出さない。そういうことを一度書けば、次からは黙っていても守られます。

やさしい解説

新しく来たアルバイトに、初日に渡す紙を想像してください。店の紹介、いつも守ること、やってはいけないこと。それを CLAUDE.md という名前のファイルに、ふつうの日本語で書いて、作業する場所に置いておきます。Claude Code は始まるたびにそれを読んでから仕事にかかります。

書き方はマークダウンで、見出しと箇条書きで「この店について」「いつも守ること」「やってはいけないこと」と分けるだけです。公式の説明では、200行より短く、具体的に書くほど守られやすいとされています。「きれいに書いて」より「値段は勝手に変えない」のほうが効きます。

AIかけこみ寺の運営そのものも、この形の1枚のファイルで動いています。同じ役目のファイルを、他のAIの道具では AGENTS.md と呼びます。

例文

  • 「毎回同じ注意をしてる気がする」「CLAUDE.md に書いておけば、次から言わなくて済むよ」
  • 「プログラムのファイル?」「ちがう、ふつうの文章。アルバイトに渡す紙と同じ」
