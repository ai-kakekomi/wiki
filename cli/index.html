CLI上級

Command Line Interfaceコマンドライン・インターフェース文字を打って機械に指示する画面

絵やボタンではなく、文字を打って機械に指示する画面です。

なぜ大事?

バイブコーディングの道具の多くは、この画面で動きます。 黒い画面に白い文字が並ぶあれです。見た目で身構えてしまう人が多いのですが、やっていることは「言葉で頼む」だけです。

やさしい解説

ボタンを押す方式は、できることが並んでいて分かりやすい反面、並んでいないことはできません。文字で打つ方式は、覚えるまでは不親切ですが、組み合わせが自由で、同じ作業をまとめて機械に任せられます。

たとえば「この folder の中の写真を全部小さくして」を、ボタン方式なら1枚ずつ、文字方式なら1行で頼めます。

昔は呪文のような書きかたを覚える必要がありましたが、いまは日本語で頼める道具が出てきました。Claude Codeがその例です。黒い画面に日本語で「これを直して」と打つ、という使いかたになります。

見た目が怖いだけで、中身は会話です。

例文

  • 「黒い画面が出てきて怖い」「あれがCLI。いまは日本語で頼めるものもあるよ」
  • 「ボタンのほうが楽じゃない?」「まとめてやりたいときは文字のほうが速いんだ」
