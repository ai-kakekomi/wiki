## ひとことで

日本語で頼むと、コードを読んで、書いて、動かして、直してくれるAIの開発ツールです。

## なぜ大事?

生成AIにプログラムを書かせること自体は、以前からできました。ただ、返ってきたコードを自分でファイルに貼り、動かし、エラーが出たらまたAIに聞く、という往復が必要でした。この往復が、初心者にとっての壁でした。

Claude Codeは、この往復ごとAIの側に渡します。公式ドキュメントの説明では、コードベースを読み、ファイルを編集し、コマンドを実行し、開発ツールと連携するツールとされています。つまり、頼む側は「何を作りたいか」を日本語で言えばよく、手順は任せられます。

AIかけこみ寺にとって、これは決定的な意味を持ちました。エンジニアを雇えない小さな団体が、LP、メンバー限定サイト、出席管理、そしてこのかけこみWikiまで自前で持てるようになったのは、この種の道具があったからです。教室でAIの使い方を教える団体が、自分たちの運営基盤もAIで作っている。掲げているHOW（AIで善意をスケールする）を、そのまま自分に適用している形です。

## やさしい解説

Claude Codeは、隣に座ってくれる腕のいい先輩エンジニアだと考えてください。

ふつうのAIチャットは、電話越しの相談相手です。こちらが状況を説明し、返ってきた助言を自分で実行します。Claude Codeは、あなたのパソコンの前に座っています。フォルダの中身を自分で見て、必要なファイルを開き、書き換え、テストを走らせ、失敗したら原因を調べて直します。説明する手間が省ける、というのが本質的なちがいです。

使う場所はいくつかあり、ターミナル（黒い画面に文字を打つ道具）、VS Codeなどのエディタ、デスクトップアプリ、ブラウザから選べます。ターミナルの場合、作業したいフォルダに移動して起動し、あとは日本語で頼むだけです。

```bash
cd my-project
claude
```

そのあとの頼み方は、こんな調子です。

> 記事一覧ページで、公開日の新しい順に並ぶようにしてください。テストも通しておいてください。

すると、関係するファイルを探し、変更案を示し、承認を得てから書き換え、テストを走らせます。Gitの操作も任せられるので、変更をコミットしてブランチを作り、プルリクエストを出すところまで頼めます。

もう1つ重要なのがCLAUDE.mdという仕組みです。プロジェクトの決まりごと（使う言葉づかい、禁止事項、ファイルの置き場所）を書いたファイルを置いておくと、毎回の作業でそれを読んでから動きます。かけこみWikiにも、記事の書き方の掟を書いたCLAUDE.mdが置かれています。人間の新人に渡すマニュアルと同じ役割です。

注意点を3つ。第1に、実行の権限を持つ道具なので、何をしようとしているかを承認する画面はきちんと読むこと。ファイルを消す操作を素通りさせると、取り返しがつきません。第2に、個人情報を含むファイルを扱わせないこと。AIかけこみ寺でも、名簿の操作は専用の手順に限定し、氏名やメールを画面に出さない設計にしています。第3に、出てきたコードの内容を理解しないまま公開しないこと。動くことと、安全であることは別です。
