GitHub Actionsギットハブ・アクションズ置き場に置くと自動で走る仕組み

GitHubに置いたとき、決めた作業を自動で走らせる仕組みです。

なぜ大事?

人が忘れる作業を、機械に肩代わりさせられます。 送るたびに検査する、送るたびに本番へ出す。毎回手でやると、忙しい日に必ず抜けます。

やさしい解説

「こうなったら、これをして」を書いた紙を置いておくイメージです。「誰かが送ったら、検査を走らせて」「本線に入ったら、サイトを作り直して」といった具合です。

書いた紙は置き場の中に入れておき、条件が満たされると勝手に動きます。結果は画面に緑のチェックか赤いバツで出るので、通ったかどうかがひと目で分かります。

ひとりで作っていても役に立ちます。検査を自動にしておけば、うっかり壊したまま公開する事故が減ります。

無料の枠があり、小さな用途なら払わずに使えます。

例文

  • 「毎回テストを走らせるのを忘れる」「GitHub Actionsに任せると、送るたび勝手に走るよ」
  • 「緑のチェックって何?」「自動の検査が通ったって印だよ」
