HTML中級

HyperText Markup Languageハイパーテキスト・マークアップ・ランゲージページの中身と構造を書くための言葉

ホームページの中身と、その組み立てかたを書くための言葉です。

なぜ大事?

いま見ているこのページも、HTMLでできています。 ホームページは3つの言葉で作られていて、そのうち「何が書いてあるか」を担当するのがこれです。バイブコーディングで作ったものを直すとき、どこを触ればよいか分かります。

やさしい解説

ホームページは、役割の違う3つで組み立てます。

  • HTML … 骨。見出し、段落、画像、リンクといった中身
  • CSS … 服。色、大きさ、並べかた
  • JavaScript … 動き。押したら開く、といったふるまい

HTMLだけでも読めるページになります。飾りがなく、動きもありませんが、中身は全部そこにあります。

書きかたは、中身を目印ではさむ形です。

<h1>かけこみ辞典</h1>
<p>むずかしい言葉に出会ったら、ここへ。</p>

<h1> が見出し、<p> が段落。マークダウンで # が見出しになるのと、考えかたは同じです。マークダウンは、これを人が書きやすくしたものだと思ってください。

例文

  • 「ホームページって何でできてるの?」「HTMLとCSSとJavaScript。中身を書くのがHTMLだよ」
  • 「文字を変えたいんだけど」「それならHTMLのほう。色を変えたいならCSSだね」
