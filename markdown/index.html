マークダウン

マークダウン中級

Markdownマークダウン記号だけで見た目を整える書きかた

記号をいくつか覚えるだけで、見出しや箇条書きを作れる書きかたです。

なぜ大事?

AIに指示を書くとき、GitHubに説明書を置くとき、掲示板に投稿するとき。いま文章を書く場所の多くが、この書きかたに対応しています。 覚える記号は5つほどで、一度覚えると一生使えます。

やさしい解説

覚えるのはこれだけです。

  • 行頭に # … 見出し。## なら小見出し
  • 行頭に - … 箇条書き
  • 言葉を ** ではさむ … 太字
  • 行頭に > … 引用
  • 言葉を ` ではさむ … そのままの文字（記号を記号のまま見せたいとき）

ワープロのように、マウスでボタンを押す必要がありません。打ちながら形が決まるので手が止まらず、書いたものはただの文字なので、どの機械でも開けます。20年後も読めます。

AIへの指示にも効きます。見出しと箇条書きで整理して渡すと、意図が正しく伝わりやすくなります。

例文

  • 「太字ってどう書くの?」「言葉を ** ではさむだけ。それがマークダウン」
  • 「ワードじゃだめ?」「ただの文字だから、どこでも開けるのが強みだよ」
